# 05. Statistics

## Topics Covered

| Topic | Description |
|---|---|
| Mean | Average |
| Median | Middle value |
| Variance | Data spread |
| Standard Deviation | Distribution |
| Probability | Likelihood |
| Correlation | Relationship between variables |

---

## Important Formulas

### Mean

```text
μ = Σx / N
```

### Variance

```text
σ² = Σ(x - μ)² / N
```

---

## Why Statistics Matters

Statistics is the foundation of:

- machine learning
- probabilistic models
- data analysis
